# Bitapres
Aplikasi desktop lokal berbasis Python dan FFmpeg untuk mengompres ukuran video sesuai target MB tanpa perlu koneksi internet.

## Fitur (Rencana)
- Kompresi video berdasarkan target ukuran (MB)
- Berjalan 100% lokal (aman untuk file pribadi)
- Tampilan desktop sederhana

## Progres Pengembangan
- [x] Setup lingkungan kerja, venv, dan GitHub
- [x] Logika inti kompresi di terminal
- [x] Antarmuka pengguna (GUI) dengan CustomTkinter
- [x] Build ke file .exe
